\begin{enumerate}
    \item[1.3] Show that if $a =_\alpha c$ and $b =_\alpha d$ and both $[b/x]a$ and $[d/x]c$ are defined, then $[b/x]a =_\alpha [d/x]c$
\end{enumerate}

The definition of $\alpha$-equavlence is given as the strongest congruence satisfying
\begin{enumerate}
    \item $x =_\alpha x$
    \item $o(\vx_1.a_1;\dots;\vx_n.a_n) =_\alpha o(\vx'_1.a'_1;\dots;\vx'_n.a'_n)$ if for every $1 \leq i \leq n$, $\hat{\rho_i}(a_i)=_\alpha \hat{\rho_i}'(a'_i)$ for all fresh renamings $\rho_i: \vx_i \leftrightarrow \vz_i$ and $\rho'_i: \vx'_i \leftrightarrow \vz_i$
\end{enumerate}

And substitution for ABTs is defined as
\begin{enumerate}
    \item $x =_\alpha x$
    \item $[b/x]o(\vx_1.a_1;\dots;\vx_n.a_n) = o(\vx_1.a'_1;\dots;\vx_n.a'_n)$ where $\forall i$ we require $\vx_i \notin b$ and we let $[b/x]a_i$ if $x \notin \vx_i$ else $a'_i = a_i$ 
\end{enumerate}

Trivially, two ABTs $a$ and $b$ can be considered equivalent if $a =_\alpha b$, so by simple substitution $[b/x]a =_\alpha [d/x]c$.

\br

Formally, however, let each ABT $s$ expand to $o_s(\vx_{s,1}.a_{s,1};\dots;\vx_{s,n})$. 

Then, $[b/x]a$ expands to $o_a(\vx_{a,1}.a'_{a,1};\dots;\vx_{a,n}.a'_{a,n})$ with $a'_{a,i} = [b/x]a_{a,i}$ if $x \notin \vx_{a,i}$ else $a'_{a,i} = a_{a,i}$

Similarly $[d/x]c$ expands to $o_c(\vx_{c,1}.a'_{c,1};\dots;\vx_{a,n}.a'_{a,n})$ with $a'_{a,i} = [b/x]a_{a,i}$ if $x \notin \vx_{a,i}$ else $a'_{a,i} = a_{a,i}$

\br

Since $a =_\alpha c$, we know $\hat{\rho_{a,i}}(a_{a,i}) =_\alpha \hat{\rho_{c,i}}(a_{c,i})$ for all $i$ and for all fresh renamings $\rho_{a,i}$ and $\rho_{c,i}$
