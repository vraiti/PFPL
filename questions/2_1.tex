\begin{enumerate}
    \item[1.3] Show that if $a =_\alpha c$ and $b =_\alpha d$ and both $[b/x]a$ and $[d/x]c$ are defined, then $[b/x]a =_\alpha [d/x]c$
\end{enumerate}

The definition of $\alpha$-equavlence is given as the strongest congruence satisfying
\begin{enumerate}
    \item $x =_\alpha x$
    \item $o(\vx_1.a_1;\dots;\vx_n.a_n) =_\alpha o(\vx'_1.a'_1;\dots;\vx'_n.a'_n)$ if for every $1 \leq i \leq n$, $\hat{\rho_i}(a_i)=_\alpha \hat{\rho_i}'(a'_i)$ for all fresh renamings $\rho_i: \vx_i \leftrightarrow \vz_i$ and $\rho'_i: \vx'_i \leftrightarrow \vz_i$
\end{enumerate}

And substitution for ABTs is defined as
\begin{enumerate}
    \item $x =_\alpha x$
    \item $[b/x]o(\vx_1.a_1;\dots;\vx_n.a_n) = o(\vx_1.a'_1;\dots;\vx_n.a'_n)$ where $\forall i$ we require $\vx_i \notin b$ and we let $[b/x]a_i$ if $x \notin \vx_i$ else $a'_i = a_i$ 
\end{enumerate}

\br

Trivially, ABTs are always defined up to $\alpha$-equivalence, so by simple substitution $[b/x]a =_\alpha [d/x]c$.
